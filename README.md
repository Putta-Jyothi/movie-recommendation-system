\# 🎬 Movie Recommendation System



A Machine Learning based movie recommendation web application developed for the \*\*SIH Internal Hackathon 2026\*\*.



The application recommends movies similar to a movie selected by the user using \*\*Content-Based Filtering\*\*.



\---



\## 📌 Project Overview



The Movie Recommendation System helps users discover movies based on their interests.



The system analyzes movie features and calculates similarity between movies. When a user selects a movie, the system recommends the \*\*Top 5 similar movies\*\*.



The application also uses the \*\*TMDB API\*\* to display additional movie information.
